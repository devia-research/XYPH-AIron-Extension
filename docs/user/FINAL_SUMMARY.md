## 📋 Guide d'Installation Rapide

### Extension Actuelle (Prête à utiliser)
```bash
# 1. Ouvrir Chrome
chrome://extensions/

# 2. Activer mode développeur

# 3. Charger extension
f:\Scripts\ExtensionChrome\

# 4. Renommer sidebar-new.html
mv sidebar-new.html sidebar.html

# 5. Tester l'extension
```

### Nouveau Projet (Développement)
```bash
# 1. Aller dans le projet
cd F:\Git\XYPH-Project\

# 2. Installer dépendances
npm install

# 3. Build de développement
npm run build:dev

# 4. Charger dans Chrome
# Pointer vers le dossier dist/
```
